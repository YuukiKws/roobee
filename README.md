# Roobee

日本語のウェブページを読んでいるだけで、単語に英単語のルビが表示される
Chrome拡張機能です。単語帳アプリのように意識して開かなくても、日常的に
英単語に触れる機会を増やすことをコンセプトにしています。

- 日本語ページ内の名詞・動詞・形容詞に、対応する英単語を上付きで表示
- クリックすると、英単語・カタカナ読み・類義語・(動詞の場合は)過去形/過去分詞を表示
- ラベル表示は「英語」「カタカナ」で切り替え可能
- 単語ごとに表示ON/OFFを個別設定可能(検索機能付き)
- 現在**3,000語**収録、継続して語彙を拡充中

## インストール方法

Kuromoji.js本体と形態素解析用の辞書データは、このリポジトリに同梱済みです。
別途ダウンロードする必要はありません。

1. 右上の「Code」→「Download ZIP」でこのリポジトリをダウンロードする(または`git clone`する)
2. 解凍してできた`roobee-main`フォルダ(そのままの名前でOK)を用意する
3. Chromeで `chrome://extensions` を開く
4. 右上の「デベロッパーモード」をONにする
5. 「パッケージ化されていない拡張機能を読み込む」から、`roobee-main`フォルダを選択する

## 使い方

1. ツールバーのアイコンをクリックし、「ルビ表示」をONにする
2. **ページを再読み込みする**(ON/OFFの切り替えはページ再読み込み後に反映されます)
3. 日本語のニュースサイトやブログなどを開くと、単語にラベルが表示されます
4. オレンジ色の単語をクリックすると、詳細(カタカナ読み・類義語・過去形など)がポップアップ表示されます
5. ツールバーの「単語ごとの詳細設定を開く」から、特定の単語だけ表示をOFFにすることも可能です

## 制限事項

- 形態素解析(Kuromoji + IPADIC)の都合上、「遊べる」のような可能形や、一部の
  活用形は、元の動詞(「遊ぶ」)とは別の語として個別に登録しないと反応しません。
  気になる語があれば、随時追加していきます。
- な形容詞・い形容詞の一部には対応していますが、副詞は基本的に対象外です
  (「擬態語+する」型の語は例外的に対応しています)。

## ライセンス

同梱している Kuromoji.js および IPADIC辞書データのライセンス表記は
